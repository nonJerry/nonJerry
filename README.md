## Hi, I'm Jeremy 👋

Software engineer focused on CI/CD and developer tooling. I like building pipelines people can rely on, that don't keep anyone waiting and need as little manual work as possible.

Currently finishing my M.Sc. in Computer Science, with a focus on distributed systems and networks. As part of it I did an exchange year at Keio University in Tokyo, so feel free to hit me up if you have any questions.

**What you'll find here**
- **[tmodloader1.4-with-web-dashboard](https://github.com/nonJerry/tmodloader1.4-with-web-dashboard)**: containerised game server with a small web dashboard, published as Docker images and kept up to date by a daily GitHub Actions workflow.
- **[VeraBot](https://github.com/nonJerry/VeraBot)**: Discord bot that verified memberships via OCR, which I ran on my own for five years until retiring it.
- **[playwright-bdd](https://github.com/vitalets/playwright-bdd)**: fixed scenario outlines, which were broken in every non-English Gherkin language.

I also run my own segmented home infrastructure: rootless Podman services on CentOS Stream behind OpenWrt, with automated certificate renewal and distribution. The scripts and systemd units behind it are public in **[homelab-automation](https://github.com/nonJerry/homelab-automation)**, alongside **[podman-nextcloud](https://github.com/nonJerry/podman-nextcloud)** and **[podman-openwisp](https://github.com/nonJerry/podman-openwisp)**.
Maybe I will publish some gists with some of my learnings and scripts I used.
